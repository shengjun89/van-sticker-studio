# 房车空间布局数据管线：采集 → 清洗 → 转化

- 版本：v0.1，2026-10-24（用户拍板数据政策后立档）
- 定位：MXGARAGE 12–24 个月产品主线的数据基建，不替代桥收入战役（2027-01-31 首单回款、02-28 硬复审仍是主线）。
- 上游构想：2026-10-23 晚用户提出的全媒体抓取 → AI 可学数据 → AI 改装全案 → 拖拽自定义 → 工厂 GEO → 订阅。

## 一、数据政策（用户 2026-10-24 晚拍板）

1. **抓取只供自己研究**：采集来的布局素材是研究资料，不是商品。
2. **原始素材不出售、不商用**：不卖原图、不把原设计图直接放进任何对外产品、方案包或宣传物料。
3. **转化成数字资产才是产品**：对外流通的只能是经清洗、抽象、重构后的衍生资产（参数模板、布局模式、尺寸规律），不是原始素材本身。
4. **原始素材永不外流**：原始库与产品库隔离存放；原始图不上传公开仓库、不发社交平台、不给客户。

补充说明（不改变政策，只防踩坑）：研究用途降低的是商业风险，不是免责牌——采集仍只碰公开内容，不绕登录墙、不碰私域（朋友圈、非公开群、付费墙内），并遵守平台规则；每条记录都留来源，授权状态不明的一律按“不可商用”处理。

## 二、管线四段

### 1. 采集（研究库，只进不出）

- 来源三条线：①公开索引（小红书/B站/Instagram/Pinterest/YouTube 等公开帖；抖音站内不对外索引、网页端常被登录墙拦截，不作直抓源，抖音内容只走②用户转发或跨平台同款转载）；②用户转发（车主、改装厂发来的实拍与图纸，须确认对方同意研究使用；用户直接发的视频文件/截图是最稳的分析源）；③自产（桥收入真实项目、用户自己的车改装案例 0——权属最干净，优先）。
- 每条采集记录必填：来源平台、原帖链接、作者（有才写）、采集时间、授权状态（自产 / 已授权 / 公开研究 / 未确认）。
- 原始文件（图、视频、图纸）存内部研究库，编号管理，不进入产品库。

### 2. 清洗（结构化，不猜数）

- 去重：同一布局的多图、多帖归成一条记录。
- 按 schema 提取（见第三节），缺失字段标“未知”，不估算、不脑补尺寸。
- 尺寸归一为毫米；区间只记区间（如床长 1800–1950），不取中值冒充精确值。
- 合规标注：燃气、电路、配重、年检公告相关的布局点单独打标签（沿用需求池 P13 的合规优势）。

### 3. 转化（衍生资产，产品库）

- 从记录中抽参数与模式，不带原始图：功能区组合（如纵床 + 尾厨）、尺寸区间、动线宽度、适用人群/场景。
- **单一来源原样输出不进入商品库**：衍生模板须经多源融合或自产改造，标注来源构成；可识别的原设计不得直接变商品（防“洗稿式”复制）。
- 衍生资产形态：布局参数模板、功能区组合模式、尺寸规律统计——供 P0 模板匹配 + 参数化 + 合规规则层调用，不直接生成可施工图纸。

### 4. 产品化（与 10-23 建议一致）

- P0 首版：模板匹配 + 参数化 + 合规规则层，单车型 V80 打穿，不急上生成式 AI。
- 早期变现仍在 C 端方案包、施工图包、施工对接抽成、改装厂白标 SaaS；订阅/广告是第三幕。
- UGC 转售另案：须先在用户条款中取得授权，只卖模板灵感不卖可施工图纸。

## 三、一条布局记录的 schema（v0.1）

| 字段 | 说明 |
| --- | --- |
| id | 记录编号，如 L0001 |
| 车型 / 底盘 | 如大通 V80-C 6 座纵床版；未知则标未知 |
| 外廓尺寸 | 长 / 宽 / 高（mm，区间或未知） |
| 轴距 | mm，未知则标未知 |
| 功能区 | 床 / 厨 / 卫 / 座 / 储物 / 工作区，各自位置（前 / 中 / 后 / 左 / 右） |
| 床 | 尺寸、方向（纵 / 横）、固定 / 升降 / 拼接 |
| 动线 | 过道宽、入口侧（左 / 右 / 后） |
| 载人 | 座位数、睡位数 |
| 人群 / 场景 | 如两人旅居、带娃家庭、钓鱼露营；未知则标未知 |
| 来源 | 平台、原帖链接、作者、采集时间 |
| 授权状态 | 自产 / 已授权 / 公开研究 / 未确认 |
| 原始素材编号 | 内部研究库编号，不对外 |
| 衍生资产 | 由此记录参与生成的模板 ID / 参数摘要（无则空） |

## 四、第一批数据的落点

- 001 号：用户自己的车（案例 0）——自产、权属干净，等用户发照片与三行文字后按 schema 落成。
- 之后每成一单桥收入项目，交付物同步沉淀一条自产记录：真实项目即自产数据生产线。
- 研究库条目只有在“授权状态”明确且完成转化后，才允许进入产品库；未确认的一律留在研究库。

## 五、本管线不做的事

- 不做全网无差别爬虫；不绕登录墙；不碰私域内容。
- 不卖、不发、不外传任何原始素材；不把单张原图包装成商品。
- 不在桥收入战役结束前把管线升级为主线；管线只做“ schema + 小批量自产记录”的最小闭环。
