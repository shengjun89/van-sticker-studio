# 验证计划（validation-plan）

> 日期：2026-10-08 · 来源：9-25 复核 §"第一阶段验证与讨论"（管理假设，非行业标准）
> 原则：先收钱，再建造。不先开发完整小程序。

## 验证方式

1. **访谈**：首月 10 家 B 端（改装门店/厂家/租赁商）+ 5 名 C 端车主。提纲见 `interview-guide.md`，纪要存 `docs/interviews/`。
2. **付费试单**：争取 **3 笔非亲友付费试单**，范围明确、限车型（MAXUS V80 起）、限修改次数、限交付期限。
   - 试单类型示例：B 端数字展示包（含选配确认/交车教学物料）、C 端拉花设计服务、1:64 小样（供应链验证通过后）。
   - 演示物料：van-sticker-studio / rv-a27-viewer 网页演示（已有资产，零开发成本）。
3. **不做的**：完整小程序开发、全国门店撮合、无限会员、囤货备料。

## 验证成本

- 时间：约 1 个月（访谈）+ 试单交付工时（单项目 30 小时交付上限，是否可行由试单判断）。
- 金钱：内容制作与差旅等小额成本；不预付大额研发/供应链投入。
- 记录要求：每单记录成交来源、报价与实际收款、全部工时、修改次数、外包成本、退款、客户使用结果。

## 通过门槛（全部满足才算验证通过）

| # | 门槛 | 说明 |
|---|---|---|
| 1 | 3 笔非亲友付费试单完成交付 | 按约定范围完成至少 2 单 |
| 2 | 现金贡献率 ≥70% | （实收 − 外包 − 获客 − 退款 − 订单相关软件成本）/ 实收 |
| 3 | ≥1 名客户付费追加或转介绍形成付费单 | 证明不是一次性人情单 |
| 4 | 30 小时交付上限可行 | 由试单实际工时判断 |

## 未达标时的处理

- 优先调整客户/产品范围，不以"继续增加免费定制"掩盖问题。
- 若 B 端连续谈不下：回到 problem-hypothesis 挑战清单，检查是价值主张问题还是触达问题；考虑转向 C 端设计服务或暂停。
- 若贡献率 <70%：拆单核算，砍掉亏损环节（限单/调价/简化可制作范围）。
