# 留言区：尚未拍板的问题

版本：2026-10-27。已退出 grill-me；这些问题供异步回复，不要求一次答完，也不再重复问已确认内容。除明确标“建议”外，不存在默认获批的答案。开发可以继续不依赖这些答案的模块。

回复方式：直接写 `Qxx：答案`，或在文档评审 / 代码任务中引用编号。确认后更新相应规格，保留变更记录，不只埋在聊天里。

## A. 影响数据和真实闭环，应优先交接

| 编号 | 需要确认 | 已知依据 / 为什么需要 |
| --- | --- | --- |
| Q01 | 已找到仓库公告数据库；本次首批具体采用哪些型号 / 年份 / 轴距顶高组合？哪些被确认属于指定底盘系列？ | 远端 `lib/announcement-db.json` 有 35 行（24 数值完整 / 11 部分），来源声明含公告与镜像；完整记录仍有未确认底盘备注，不能直接当首批已验证系列 |
| Q02 | 8 套配色 / 拉花的代码、分支或资产目录在哪里？准确名称、预览和贴图是什么？ | 当前可访问代码有 4 个 sample；历史 10 案不是同一套 8 枚举，不能自行拼凑 |
| Q03 | 首批车型可用净空间、地板、轮包、门窗开口和固定驾驶室 / 轮心的可信来源是什么？哪些可先标“模型候选”？ | 已有公告字段门禁不能证明程序化白模几何与实车一致；外尺寸不等于内净宽，不能直接拉伸历史网页模型校准 |
| Q04 | P0 真实图像服务用哪家、谁提供服务端凭据与额度？ | 既有拉花 API 不等于四机位装修服务；接入前需真实验证布局保真，不能仅指定模型名就视为满足 |
| Q05 | 登录、云保存使用现有哪个账号 / 后端？是否已有团队标准？ | 游客可本地用，但出图 / 云保存 / 会员下载门禁要落真实能力，不能假登录或假云存 |
| Q06 | Blender / FreeCAD 下载的首版交付格式及“可编辑”要求？ | 已确认保留独立低模和层级；尚未确认 GLB / OBJ / STEP / FCStd，网格导入不等于原生参数化 CAD |

Q01–Q03 不阻碍复用已有公告门禁、画布壳、数据结构及单一可信模型试点；但阻断“首批真实车型与 8 套均完成”的声明。Q04–Q06 不阻碍适配器和本地流程，但阻断对应真实能力验收。

## B. 交互语义尚有空白，不应由工程师静默拍板

### Q07 删除模型卡后的结果与任务

最后一轮访谈尚未回答：删除模型卡时，历史图片是否保留？生成中任务继续还是提示取消？用户是否能撤销删除？保留图如何访问源版本？

没有已批准默认。建议评估保留不可变来源快照、明确运行中任务后果，避免孤儿结果或误扣额度；这是建议，不是用户确认。

### Q08 在已有布局上应用另一个模板

已确定在当前卡替换，不自动新增模型卡、不自动挪动旧家具。尚需确认覆盖前的二次确认、快照是否与“清空布局”共用，以及是否允许仅预览不应用。

### Q09 快照与历史

已确认清空前存完整快照，恢复车型 + 布局。保留多少份、恢复是否可再次撤销、是否面向用户展示完整版本列表、何时清理本地历史尚未定。

### Q10 取消任务、额度预占与结算

已确认取消独立于撤销，重试必须显示预计消耗；未确定排队 / 运行 / 部分成功时能否取消、服务实际成本怎么算、失败是否扣额度、何时返还或释放预占。界面不能提前承诺退款。

### Q11 机位、风格与模板内容

已确定固定 1 外观 + 3 内景、选一个预置装修风格。首批风格名称 / 数量、各车型模板清单、默认通用布局、三内景位置和遮挡可接受标准尚未定。建议用真实布局做受控试样后再锁；不再开放复杂相机给用户。

### Q12 空调的首个基础白模

采用哪种具体机型 / 形式？可支持高位柜内的分体室内机有官方先例，但地板风管机、顶置机不能通用塞吊柜。型号决定安装面、包络、进出风、检修、排水及外机提示；未知时不能凭空定安装净距。

### Q13 登录后的本地项目迁移

是否自动上传本地项目、要不要用户确认、已有云端项目如何冲突处理、退出登录后本地副本怎么显示？P0 是否只支持个人单设备编辑？多人协作暂未列为已确认能力。

### Q14 卡片及对话的作用域

已确定聊天输入引用当前模型，任务固定版本。聊天历史是项目级还是模型卡级？如何从结果卡定位源模型？卡片精确尺寸、结果卡网格、触控 / 轨迹板手势以及当前动作优先级尚未出稿。

### Q15 基础下载与会员演示

已确定四类能力独立、P0 无真实支付。基础图片分辨率 / 水印、会员图片规格、测试会员如何开通、额度计量单位 / 初始额度、下载待更新或不合格图时的提示 / 限制仍待确认。

## C. 技术验证后回报，不必现在让产品负责人选技术

- 同一布局四机位的真实 AI 结构一致性可达到什么水平？如何生成控制参考、识别不合格、人工兜底？不能保证时必须回报，不偷偷放宽“不能改布局”。
- 网页低模在 Blender 和 FreeCAD 的导入、单位、对象名、父子、材质实际保留情况，是否需要双格式 / 中间清单？
- 允许哪些形状参数才能可靠重算内空间、开口和配件约束？实际资产是否具备参数来源？
- 多模型卡的实时预览成本、本地存储容量、离线图片策略、后台任务恢复方式；提出测量和取舍，不编造性能门槛。

技术建议由开发团队在 [架构](ARCHITECTURE.md) 或新 ADR 中记录，涉及产品行为变化再请负责人确认。
