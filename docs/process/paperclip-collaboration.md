## 目标与权威边界

Paperclip 管理运行队列、实际接收/执行回执、任务看板、运行记录和成果入口。GitHub 保留规则、批准范围、冻结验收、原 claim、代码、PR、完整 SHA、CI、独立结论和原始验收证据。Cloudflare 保留网站运行、实际生产版本、资源绑定与流量记录，发版沿用 DEPLOY.md §2.4 和 AGENTS §13；任务 done、合并、版本上传和生产切流量分别记录。

Paperclip 是 dot 的协调机制，不是新增授权来源。界面中的在线、暂停或任务锁不证明外部 run 停止；单 Issue checkout 不替代跨任务文件/语义锁。凭据、预算、安全权限和保护治理按原保留项处理。

## 请求映射与准入

每个可执行请求至少绑定：仓库、原 GitHub Issue、工作切片、claim、切换代次、Paperclip company/project/issue/run、实际执行者及平台 run、完整 base/head、冻结 spec/验收、文件/语义锁、授权动作/次数和已消费次数、依赖、状态证据、下一责任人。未知填未知；本地记录 ID 不能冒充平台 run ID。

去重键使用 `仓库 + 原Issue + 工作切片 + claim + 切换代次`，通过持久记录和原子准入核对，不靠评论先到或内存变量。旧代次与结果未知请求先对账，不能创建新请求掩盖旧结果。原始 stopped/blocked 任务先以未分配、无执行触发的记录迁入；无合格独立角色时保持原阻塞和具体下一步。

每人一个活动实现；文件/语义锁跨 Issue 检查。Paperclip checkout 只解决同任务竞争，未验证跨任务互斥前不开放自动实现派单。requested、accepted、running、blocked、completed 沿用 AGENTS §11；外部 HTTP 2xx、事件已送达、页面显示 running 分别不足以证明 accepted、实际开工和完成。

## 单入口切换验收

1. 先完成所有者认领、登录、稳定 HTTPS、数据持久化/备份及真实可访问性检查。全新实例不得在未认领时公开；authenticated/public 按官方高熵管理员邀请流程，不依赖私网首次认领行为。
2. 每种外部 agent 分别配对，用不创建开发任务的事件测试证明收件；再用一个已批准无外部写入的只读任务证明 accepted、run、结果及完成回执。Dot/Grok/Muse 的能力与资格分别核实，不按昵称假定接通。
3. 检查该固定版本的自动恢复、transient retry、缺评论续跑、会话回退、watchdog 和周期唤醒。须有可验证的准入策略阻止未授权重试、许可重置和用户停令下的新执行；提示词约定不足以证明隔离。无法约束的执行路径保持关闭/不接入，不靠换名称或新 run 绕过。
4. 验证重复事件不重复执行、一人一实现、跨任务冲突阻断、未知结果对账、停止不抢锁，以及 Paperclip 失联时不启用备用派单。
5. 先告知用户旧值守从主动派单改为只读对账的对象、影响、执行条件及回退。读回配置并核实旧轮次在途写入；旧轮次状态未知时不允许新入口派发重叠工作。
6. 在 #56 和 #27 写明唯一派单源、切换代次、时点、任务映射、已迁入/未迁入项及证据。仅此后开启 Paperclip 准入；现有验收和原锁不因切换改变。

## 发布与实时看板

看板显示任务负责人、实际状态、最近回执、原 PR/完整 SHA、CI、阻塞责任人、产物和 Cloudflare 预览入口。运行日志及费用以适配器实际回传为准；外部 Dot 的费用和完整私有对话不可见，不补造进度百分比。截图/视频是已产出证据，不宣称持续屏幕直播。

应用预览须关联实际构建版本及资源/费用边界；开发服务与 HTTPS ready 分别验证。Cloudflare 的实际构建命令/触发器尚未由本迁移核验，不能从文档或 PR 预览成功推定 main 仅上传版本。Paperclip 不安装第二条网站发布流水线，不存生产密钥，不由任务 done 直接切流量。

## 配置通知、失败与回退

配置变更单包含：对象/责任人、旧/新行为、权限/费用/数据影响、在途动作、条件与检查、非敏感读回结果、回退。会话签名、管理员邀请、配对码、模型/平台凭据均不进仓库、Issue、截图或普通日志。

失败停止该动作，保留原错误；不由健康检查或新巡检自动恢复 agent。Paperclip 故障时保留原任务与锁，旧值守只对账，不自动恢复派单。回退需确认新入口无在途写入、保存任务/锁/成果与配置、分配新代次、验证唯一旧入口，通知用户后执行；不能回退到旧 spec 弱化验收。

首次交付分别报告：安装、服务健康、认证/所有者、持久化、可访问入口、agent 配对、单派单验收、正式规则生效与生产发版。未完成项保留明确责任人和下一事件，不能合称“已部署接管”。
