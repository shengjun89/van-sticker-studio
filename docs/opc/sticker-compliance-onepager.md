# 拉花 / 外观装饰合规说明（一页纸·草稿）

> 用途：B 端门店谈单附件 / 嘉年华现场 A9 访谈后的可信度道具
> 依据：交管部门公开口径（见文末来源），非法律意见；各地执行口径可能有差异，施工前建议与当地车管所确认

## 核心结论（先看这三行）

1. **拉花 ≤ 车身总面积 30% → 无需备案**：属于"车身装饰拉花"，不是"改变车身颜色"，改完直接上路。
2. **全车改色 / 改色面积 >30% → 10 日内必须备案**：依据《机动车登记规定》第十六条，变更后十日内向车管所申请变更登记。
3. **红线**：禁用警车 / 消防 / 救护 / 工程救险专用或近似标志图案；车身禁大面积镜面反光。

## 为什么拉花是"零验车风险"（法规底座）

- 银川交警公开口径：车身装饰拉花总面积不超过车身 30% 无需备案（2026 年夏季自驾执法提示原文）。
- 2026-09-27 行业梳理：改色面积不超过全车 30% 可免备案；车身颜色变更后 10 日内备案。
- 对比：全车改色膜 = "改变车身颜色"，走变更登记流程（交管 12123 预约 → 带身份证 / 登记证书 / 行驶证 → 车辆开到现场查验）；拉花在 30% 线内 = 不触发该流程。
- 房车提示：具体车辆的登记类别及适用口径尚未核实，施工前需向当地主管部门确认；若改装涉及行李架等结构件加装，另按"加装"口径处理，不在本页范围内。
