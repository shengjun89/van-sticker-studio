## 使用规则（先读这段）

1. **灵感库不是盗图库。** 本库只作风格参考与再创作起点：看构图、配色、线条感觉，不直接把原图拿去生产。
2. **商用必须取得授权或重绘。** 给客户出方案时，设计师须按灵感重绘并矢量化（或取得原作者书面授权）；直接描摹、直接喷绘原图都属于侵权风险行为。
3. **注明原作者 / 出处。** 对内提案、对外展示时保留本库的作者与链接信息，不抹掉出处。
4. **授权状态说明。** 本版全部条目授权状态均为「授权未确认」——即尚未向原作者确认商用授权。未确认前，一律按“只能参考、不能直接商用原图”处理。
5. **字体与标语单独注意。** 带文字的条目只参考文案方向与排版感觉，字体须重排或使用已获授权的字体；不要直接描摹原图中的手写字体。
6. **放大前必查。** 上车前一律重绘为矢量稿或高清稿；细线条要加粗到喷绘 / 刻字的安全线宽，渐变与水彩类必须确认放大后不糊。
7. **新增条目须人工复核链接有效性后追加，不自动更新。**

客户选风格 → 设计师按灵感重绘并矢量化 → van-sticker-studio 做 3D 预览 → 施工评估（贴合车窗、车门、轮拱位置）→ 客户确认后生产。灵感库只解决“风格从哪来”，不替代重绘与施工评估。
