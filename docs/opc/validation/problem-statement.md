# 问题陈述（problem-statement）

> 日期：2026-10-08 · 状态：草稿，待创始人确认与访谈验证
> 证据说明：本节基于已有研究文档（MXGARAGE 计划书 v1.0 2026-09-09、政策与轻资产复核 2026-09-25）整理；**用户访谈记录为 0**，所有"用户说"均为待验证假设。

## 一句话问题

**谁**：房车车主（尤其有拉花/改装需求的）、改装门店与房车厂家/租赁商（B 端）
**什么痛点**：在花大钱做实车拉花施工之前，车主无法在"自己的准确车型"上看到图案的真实上车效果；门店则要反复口头讲解、反复确认，售前成本高
**频率**：每次改装决策都发生一次；对门店是日常性重复劳动（待访谈量化：每单讲解耗时、返工率）
**严重度**：高——实车施工是高价、不可逆消费，决策失误代价大；门店的反复确认直接吃掉利润
**当前处理方式**：
- 车主：看通用改色案例图、听门店口头描述、凭想象决定（计划书 §1）
- 门店：人工讲解 + 效果图 PS；无"对应车型、跨视角一致"的标准化展示工具（9-25 复核）

## 两个细分问题

### P1（C 端）：车主"施工前看不清"
- 车主已有图案或想定制拉花，但在施工前只能看到平面图或别人的案例，无法确认图案在自己车型上的位置、比例、门窗遮挡关系。
- 现有替代：通用作图工具、门店口头承诺。都不解决"车型一致性"问题。

### P2（B 端）：门店"讲不清、确认难"
- 门店/厂家向客户介绍选配、内饰布局、改装方案时，依赖口头 + 静态图，反复确认耗时。
- 现有替代：宣传册、样车（重资产）。轻量数字展示工具缺失。
- 9-25 复核将其列为**首选验证方向**：B 端房车数字展示、选配确认、交车教学交付。
