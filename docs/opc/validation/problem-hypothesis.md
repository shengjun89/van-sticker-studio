# 问题假设（problem-hypothesis）

> 日期：2026-10-08 · 状态：访谈前版本——以下全部为**待验证假设**，访谈后用真实故事+数据替换/修正
> 规则：支持清单与挑战清单不对称时要追问原因；目前 0 次访谈，两张清单都基于案头研究

## 支持假设的清单（为什么这事可能成立）

1. **可演示的资产真实存在**：van-sticker-studio（拉花预览）与 rv-a27-viewer（内饰 15 项动作演示）都是可运行的网页，不是 PPT。B 端演示获客今天就能做。
   - 来源：`context/` 解包验证
2. **B 端有明确的"省时间"价值主张**：门店售前反复讲解是日常重复劳动，数字展示包若能量化"省 X 小时/单"，付费逻辑通顺。
   - 来源：9-25 复核（待访谈量化）
3. **政策顺风**：国办函〔2026〕82 号支持房车消费与租赁数字服务，B 端客户有投入数字化的政策体感。
   - 来源：9-25 复核政策核验
4. **竞品共同短板**：相邻产品多为"可视化"，条款普遍不保证可生产；"准确车型 + 交付链路"是空白身位。
   - 来源：计划书 §2.4 竞品核验
5. **轻验证路径清晰**：3 笔试单、贡献率 ≥70%、转介绍 1 个——验证成本是一个月时间，不先烧 8–10 周做小程序。
   - 来源：9-25 复核

## 挑战假设的清单（为什么这事可能不成立）

1. **0 次访谈，需求强度未知**：车主"看不清效果"可能是伪痛点——多数人可能直接信任门店，或对价格更敏感。痛点存在 ≠ 愿付费。
2. **B 端付费意愿是最大未知数**：门店习惯了免费获客方式（口头+样车），为"展示包"付 2–5 万需要决策链（老板/合伙人），销售周期可能很长。一人公司能否谈下 20 单存疑。
3. **"准确车型"是重资产**：每个车型版本需独立标定、验收（计划书 §5 F33）；MXGARAGE VAN 之外每扩一个车型都是成本。规模化悖论：做深做不大，做宽做不准。
4. **技术红利惠及所有人**：AI 生图/照片改色工具越来越多，"看清效果"正在变成免费 commodity；若差异化只停留在可视化，会被免费工具挤压。
5. **交付链路是坑**：1:64 小样需要白模供应链验证（计划书 §8：若无准确的本车型白模，不能用近似车冒充）；实车生产包需门店实测验收。任何一环不通过，闭环就断。
6. **政策是双刃剑**：改装分类管理趋严，拉花改色需按车辆类别办登记——合规成本可能转嫁到每一单，侵蚀贡献率。
7. **小众市场天花板**：房车保有量有限，C 端走量难；若 B 端 20 单目标达不到，50 万目标需重定口径。

## 当前不对称性说明

支持清单多为"资产/逻辑"层面，挑战清单多为"人性/市场"层面——后者只能靠访谈和试单回答，案头研究无法消除。这是正常的，但意味着**在拿到 3 笔试单之前，任何"继续投入"的决策都是高风险的**。
